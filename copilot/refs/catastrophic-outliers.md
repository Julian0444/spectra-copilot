In this project a catastrophic outlier is a prediction with |z_pred - z_true| / (1 + z_true) > 0.15, the eta metric reported for desi-fm (the DESI pipeline uses an equivalent velocity-error criterion). The dominant causes are line misidentification (the Halpha/[OII]/[OIII] single-line confusion), low signal-to-noise spectra, and sky-subtraction residuals mistaken for emission lines. desi-fm v2.1 flags likely outliers with z_confidence below about 0.3, which is exactly when line verification and reference lookups matter most.
